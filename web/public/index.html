How it works

Reviews are ready before you open the app.

A schedule keeps a fresh review for every open pull request, keyed to its head commit. Push again and it reviews again. Open the app and swipe.

01

Connect GitHub

Install OpenComputer's GitHub App and pick the repos. That selection is everything the agent can reach.

02

The agent reviews

Every 15 minutes it finds new PRs and new commits and reviews each one in its own sandbox: diff, full files, callers, CI logs, tests. Every finding is verified before it is reported.

03

You swipe

Right merges, left closes, the comment button posts to the PR. Every swipe waits five seconds so you can undo, and branch protection still applies.

Why OpenComputer

The whole backend is one agent file.

PR Swipe is an OpenComputer template. The web app is a thin page and a small proxy; OpenComputer runs everything else.

🧠

Managed agent loop

agent.ts returns instructions per mode. OpenComputer calls the model, runs tools and loops until the review is done.

🖥️

A computer per review

Each review gets an isolated Linux sandbox with git and gh to clone, grep and run tests.

🔑

GitHub App connection

githubApp() mints a short-lived installation token for every command. No GitHub token in your code.

📼

Durable sessions

Every list, review and swipe is a session with an event log and a typed result. That is the app's whole database.

⏰

Schedules

defineSchedule() runs the review sweep every 15 minutes. Idempotency keys make sure each commit is reviewed once.

🛡️

Secrets at the edge

The sweep's API key is attached at OpenComputer's outbound edge. The agent never sees it.

Without it you would build a job queue, sandboxed runners, GitHub App token minting, a review store, cron, and model and secret handling.

Deploy your own

Five minutes to your first swipe.

The hosted page you are on runs the demo only. Live mode merges and closes real PRs, so it runs on your deployment, with your GitHub App and your password.

Deploy on OpenComputer
  1. Deploy the template. OpenComputer creates a project from this repo and deploys the agent.
  2. Connect GitHub in the project's Connections tab, or from the app. Pick the repos to review.
  3. Set OC_API_KEY as a project secret so the background sweep can start reviews.
  4. Run the app: npm run web locally, or deploy web/ to Vercel with OPENCOMPUTER_API_KEY, OPENCOMPUTER_PROJECT and APP_PASSWORD.
  5. Swipe.
